\# Калькулятор



Простое приложение на Python для выполнения арифметических операций. Приложение простое но мне потребовалось три коммита чтобы исправить собственную невнимательность...



\## Функции

\- plus(a, b) - сложение

\- minus(a, b) - вычитание

\- proizwedenie(a, b) - умножение

\- delenie(a, b) - деление
