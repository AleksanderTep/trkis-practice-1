# Практическая работа №1-2: Git и CI/CD

Этот репозиторий содержит выполнение практических работ по дисциплине "Современные технологии проектирования информационных систем".

## Описание проекта
В папке `person1` находится простой калькулятор на Python, созданный для отработки навыков работы с системой контроля версий Git и настройки непрерывной интеграции (CI).

## Функционал
- Сложение (plus)
- Вычитание (minus)
- Умножение (proizwedenie)
- Деление (delenie)

## CI/CD
В проекте настроен GitHub Actions (файл `.github/workflows/main.yml`). При каждом коммите автоматически запускаются тесты (pytest) для проверки работоспособности кода.
